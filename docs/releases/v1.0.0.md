# Fuzzion-5000 v1.0.0

The first release of **Fuzzion-5000**, a transistor fuzz distortion built around a
starve-bias clipper.

## Highlights

- **Four transistor characters** — Silicon, Germanium, Velcro and Doom — each with
  its own clipper asymmetry, coupling filters and fixed mid contour.
- **Starve bias** offsets the operating point into asymmetric, sputtering fuzz and
  even-order harmonics, with the shape visible on the front-panel bias scope.
- **Full-wave octave up** rectifier blend with its own band-limiting.
- **Tone stack** with a 700 Hz tilt, mode mid contour and a tone-dependent low-pass
  ceiling; switchable in and out from the front panel.
- **Input-keyed noise gate** with a -72…-24 dB threshold and smooth 1.5 / 45 ms
  envelope, for gated-fuzz chops without cutting sustained notes.
- **Iron output transformer** saturation and band-limiting, switchable.
- **4x oversampled** non-linear stages with dry/wet summed at the oversampled rate,
  giving constant, reported latency and a click-free latency-matched bypass.

## Factory presets

`Init Fuzz`, `Voodoo Silicon`, `Germanium Rain`, `Octave Frenzy`, `Velcro Riot`,
`Doom Slug`, `Bass Starve`, `Sonic Cathedral`, `Broken Radio`, `Parallel Grit`.

## Formats

VST3 and Standalone for Windows x64, Linux x64 and macOS Universal (arm64 + x86_64).

## Interface

Sleek futuristic studio hardware: brushed gunmetal chassis, flush screwless glass
with a crimson LED edge-glow, low-profile knurled metal knobs, ultra-thin glass
sliders, a glowing real-time waveform screen and a live transfer/bias scope.

- VST3 host scan, parameter/program enumeration, audio processing and state

- Headless 2x UI render inspected for layout, contrast and the gunmetal/glass/crimson
  aesthetic.
